Question 2_5

Which number line models -4 - 4?

Solution

To model -4 - 4 on a number line, first rewrite the expression using addition. -4 - 4 = -4 + (-4)

Since the expression is the same as -4 + (-4), you can start at -4 on the number line and move in the negative direction 4 units.

To find the missing number, see where the arrow ends. The arrow ends at -8, so -4 + (-4) = -8. So -4 - 4 = -8.
