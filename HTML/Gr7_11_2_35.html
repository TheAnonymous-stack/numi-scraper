Question 2_35

Which number line models -2 - 11?

Solution

To model -2 - 11 on a number line, first rewrite the expression using addition. -2 - 11 = -2 + (-11)

Since the expression is the same as -2 + (-11), you can start at -2 on the number line and move in the negative direction 11 units.

To find the missing number, see where the arrow ends. The arrow ends at -13, so -2 + (-11) = -13. So -2 - 11 = -13.
