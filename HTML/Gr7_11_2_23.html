Question 2_23

Which number line models 0 - 12?

Solution

To model 0 - 12 on a number line, first rewrite the expression using addition. 0 - 12 = 0 + (-12)

Since the expression is the same as 0 + (-12), you can start at 0 on the number line and move in the negative direction 12 units.

To find the missing number, see where the arrow ends. The arrow ends at -12, so 0 + (-12) = -12. So 0 - 12 = -12.
