Question 2_34

Which number line models 8 - 9?

Solution

To model 8 - 9 on a number line, first rewrite the expression using addition. 8 - 9 = 8 + (-9)

Since the expression is the same as 8 + (-9), you can start at 8 on the number line and move in the negative direction 9 units.

To find the missing number, see where the arrow ends. The arrow ends at -1, so 8 + (-9) = -1. So 8 - 9 = -1.
