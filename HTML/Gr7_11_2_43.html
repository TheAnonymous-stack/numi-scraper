Question 2_43

Which number line models -4 - 10?

Solution

To model -4 - 10 on a number line, first rewrite the expression using addition. -4 - 10 = -4 + (-10)

Since the expression is the same as -4 + (-10), you can start at -4 on the number line and move in the negative direction 10 units.

To find the missing number, see where the arrow ends. The arrow ends at -14, so -4 + (-10) = -14. So -4 - 10 = -14.
