Question 2_10

Mario's coins started at -4 and decreased by 5 after buying power-ups. Which number line models -4 - 5?

Solution

To model -4 - 5 on a number line, first rewrite the expression using addition. -4 - 5 = -4 + (-5)

Since the expression is the same as -4 + (-5), you can start at -4 on the number line and move in the negative direction 5 units.

To find the missing number, see where the arrow ends. The arrow ends at -9, so -4 + (-5) = -9. So -4 - 5 = -9.
