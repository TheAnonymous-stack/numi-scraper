Question 2_47

Which number line models -5 - 3?

Solution

To model -5 - 3 on a number line, first rewrite the expression using addition. -5 - 3 = -5 + (-3)

Since the expression is the same as -5 + (-3), you can start at -5 on the number line and move in the negative direction 3 units.

To find the missing number, see where the arrow ends. The arrow ends at -8, so -5 + (-3) = -8. So -5 - 3 = -8.
