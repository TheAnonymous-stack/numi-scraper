Question 2_19

Basketball points started at 0 and decreased by 6 after fouls. Which number line models 0 - 6?

Solution

To model 0 - 6 on a number line, first rewrite the expression using addition. 0 - 6 = 0 + (-6)

Since the expression is the same as 0 + (-6), you can start at 0 on the number line and move in the negative direction 6 units.

To find the missing number, see where the arrow ends. The arrow ends at -6, so 0 + (-6) = -6. So 0 - 6 = -6.
