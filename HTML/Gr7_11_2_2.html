Question 2_2

Goku's power level started at 8 and decreased by 11 after fighting. Which number line models 8 - 11?

Solution

To model 8 - 11 on a number line, first rewrite the expression using addition. 8 - 11 = 8 + (-11)

Since the expression is the same as 8 + (-11), you can start at 8 on the number line and move in the negative direction 11 units.

To find the missing number, see where the arrow ends. The arrow ends at -3, so 8 + (-11) = -3. So 8 - 11 = -3.
