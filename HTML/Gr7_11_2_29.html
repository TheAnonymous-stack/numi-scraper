Question 2_29

Which number line models 3 - 8?

Solution

To model 3 - 8 on a number line, first rewrite the expression using addition. 3 - 8 = 3 + (-8)

Since the expression is the same as 3 + (-8), you can start at 3 on the number line and move in the negative direction 8 units.

To find the missing number, see where the arrow ends. The arrow ends at -5, so 3 + (-8) = -5. So 3 - 8 = -5.
